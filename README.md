## 🐳 Dockerized Node.js Task Manager

As part of my Docker learning journey, I successfully **containerized a Node.js Task Manager application** and ran it locally using Docker.

### 🚀 What I Did

* Created a **Dockerfile** to containerize the Node.js application.
* Built a Docker image named `node-application`.
* Created and started a Docker container from the image.
* Configured Docker port mapping to expose the application on **localhost:5050**.
* Verified that the application was successfully running inside the Docker container.
* Used **Docker Desktop** to monitor and manage the running container.
* Updated the application's frontend with a modern task-management dashboard.

### 🐳 Docker Workflow

```text
Node.js Application
        ↓
     Dockerfile
        ↓
   Docker Build
        ↓
 Docker Image
(node-application)
        ↓
  Docker Container
        ↓
 localhost:5050
```
